# ⌨️ Phím Tắt VS2022 & VS Code

> Tất cả phím tắt bên dưới áp dụng cho **cả VS2022 và VS Code** trừ khi có ghi chú riêng.

---

## 🔍 Điều Hướng

| Phím tắt      | Công dụng                                   |
| ------------- | ------------------------------------------- |
| `F12`         | Đi tới định nghĩa hàm / biến                |
| `Shift + F12` | Xem toàn bộ nơi gọi hàm / biến đó           |
| `Alt + ←`     | Back — lùi lại vị trí con trỏ trước đó      |
| `Alt + →`     | Forward — tiến tới vị trí con trỏ tiếp theo |
| `Ctrl + P`    | Tìm & mở file nhanh                         |

---

## 🔎 Tìm Kiếm & Thay Thế

| Phím tắt           | Công dụng                      |
| ------------------ | ------------------------------ |
| `Ctrl + F`         | Tìm trong file hiện tại        |
| `Ctrl + Shift + F` | Tìm trong toàn bộ project      |
| `Ctrl + H`         | Thay thế trong file hiện tại   |
| `Ctrl + Shift + H` | Thay thế trong toàn bộ project |

---

## ✏️ Chỉnh Sửa Code

| Phím tắt              | Công dụng                                                                   |
| --------------------- | --------------------------------------------------------------------------- |
| `Alt + ↑ / ↓`         | Di chuyển dòng code lên / xuống                                             |
| `Shift + Alt + ↑ / ↓` | Duplicate (copy) dòng code lên / xuống                                      |
| `Ctrl + X`            | Nếu **không bôi đen**: xóa cả dòng — Nếu **có bôi đen**: cắt phần đó        |
| `Ctrl + /`            | Comment / Uncomment nhanh (bôi đen nhiều dòng rồi bấm để áp dụng hàng loạt) |
| `Tab`                 | Thụt lề vào (indent)                                                        |
| `Shift + Tab`         | Thụt lề ra (unindent)                                                       |

---

## 🖱️ Chọn Vùng Code (Selection)

| Phím tắt               | Công dụng                                                     |
| ---------------------- | ------------------------------------------------------------- |
| `Shift + Alt + →`      | Expand selection — bôi đen mở rộng ra (cả thẻ / hàm / object) |
| `Shift + Alt + ←`      | Thu nhỏ selection                                             |
| `Ctrl + Shift + ↑ / ↓` | Mở rộng con trỏ lên / xuống nhiều dòng **(VS2022)**           |
| `Alt + Click`          | Đặt nhiều con trỏ cùng lúc **(VS Code)**                      |

---

## 🏷️ Rename / Refactor

| Phím tắt  | Công dụng                                                               |
| --------- | ----------------------------------------------------------------------- |
| `F2`      | Rename biến / hàm toàn bộ project (những nơi nó được dùng)              |
| `Alt + D` | Gợi ý cách giải quyết bug / quick fix **(cả 2)**                        |

---

## 🐛 Debug

| Phím tắt      | Công dụng                                                                             |
| ------------- | ------------------------------------------------------------------------------------- |
| `F5`          | Chạy debug trong cả VSCode và VS2022, còn nếu đang breakpoint thì nhấn nó sẽ Continue |
| `Shift + F5`  | Dừng debug                                                                            |
| `F9`          | Đặt / bỏ breakpoint                                                                   |
| `Ctrl + F9`   | Vô hiệu hóa breakpoint                                                                |
| `F10`         | Step Over — chạy từng dòng, không đi vào trong hàm                                    |
| `F11`         | Step Into — đi sâu vào bên trong hàm                                                  |
| `Shift + F11` | Step Out — thoát ra khỏi hàm đang ở trong                                             |
| `Alt + I`     | Mở **Immediate Window** để test hàm **(VS2022)**                                      |
| —             | VS Code có sẵn Debug Console dưới cùng màn hình                                       |

---

## 🪟 Quản Lý Cửa Sổ & Tab

| Phím tắt   | Công dụng                           |
| ---------- | ----------------------------------- |
| `Ctrl + W` | Đóng file / tab hiện tại **(cả 2)** |

## 🔬 Xem Thông Tin Code

| Phím tắt   | Công dụng                                                                          |
| ---------- | ---------------------------------------------------------------------------------- |
| `Ctrl + Q` | Xem ai đã sửa dòng code đó (Git Blame) **(VS Code — cần cài extension Git Blame)** |
| —          | VS2022: cài extension **Git Blame** là dùng được, không cần phím tắt riêng         |
